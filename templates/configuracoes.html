Como os valores são calculados

Saldo do mês = receitas menos todas as saídas, incluindo aportes. Economia é a sobra positiva do mês; não significa que ela já foi transferida para uma reserva. O saldo acumulado considera os registros até o fim do mês selecionado.

Essenciais: alimentação, transporte, moradia, educação e saúde. Investimentos são exibidos separadamente. As demais categorias são não essenciais para esta classificação simples.

Começar sem os exemplos

Os registros iniciais são fictícios. Faça um backup, pare o servidor e substitua o conteúdo de dados.json pelo modelo vazio do README. Para restaurar um backup, com o servidor parado, copie seu conteúdo para dados.json.

Uso pessoal no computador, sem login ou conexão bancária. Não publique este servidor na internet.
